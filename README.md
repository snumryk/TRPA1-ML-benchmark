# TRPA1 ML Benchmark

**Актуальна редакція: CLASSIFICATION-BAYESHERG-2026-10-10.**

## Почати з STATUS.md

**Задача:** порівняти, які класичні алгоритми та сучасні нейромережі краще
відбирають потенційні інгібітори людського TRPA1 за структурою молекул.

**Прийнято:** BayeshERG як шаблон підготовки класифікаційних даних.
**Етап:** інвентаризація джерел і підготовка нового набору, не навчання моделей.

[Актуальний стан, прийняті правила та наступна дія](STATUS.md).
[Каталог нового експерименту](experiments/trpa1_classification_v1/README.md).

Не повертатися до числової регресії як єдиної мети: рішення про класифікацію
прийняте. IC50/pIC50 залишаються підставою для класів. Межа відбору не означає,
що всі молекули нижче неї біологічно нездатні інгібувати канал.

## Межі доступу та збереження роботи

**AI використовує GitHub тільки для читання.** Заборонені прямі зміни,
commit, push, видалення, PR та відкат. Усі нові/оновлені файли передаються
користувачу в чаті; публікує виключно користувач.

Не переносити старі дані, код і результати заради нового етапу. Не змінювати
їхні контрольні суми, не запускати старі API-скрипти як «перезбірку».
Нові завантаження і перетворення мають окремі виходи в папці експерименту.
Дослідження повністю дистанційне; лабораторія в Києві не є передумовою.
