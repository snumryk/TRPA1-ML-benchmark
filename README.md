# TRPA1 ML Benchmark

**Актуальна редакція контексту: ORIGINAL-COMPARISON-2026-10-08.**

## Почати з STATUS.md

**Поточна задача:** чи можуть сучасні нейромережі точніше за класичні
алгоритми передбачати, наскільки сильно речовина пригнічує людський TRPA1?

**Етап:** уточнення вибору моделей, їхнього навчання та правил порівняння.
Не фіналізація попередньої статті й не нова assay-aware або human–rat задача.

[Прочитати повний актуальний стан і наступний крок](STATUS.md).

Попередню сітку «чотири готові описи структури × RF/XGBoost» виконано.
Вона не є завершеним порівнянням усіх обраних навчених нейромереж із
класичними методами. Попередні дані, результати й рукопис зберігаємо.
Не починаємо з нуля й не обіцяємо перемоги нейромереж.

## Як читати файли

- `STATUS.md` — єдиний актуальний опис задачі, рішень і наступних дій.
- `paper_plan.md` і `docs/paper_plan.md` — вказівники, не паралельні плани.
- `docs/methods_fact_sheet.md` — довідка про попередній виконаний експеримент.
- `data/`, `results/`, `scripts/`, `sources/` — матеріали для перевірки фактів.
- `docs/TRPA1_FULL_MANUSCRIPT_v5.docx` та старі розділи — попередній рукопис,
  а не інструкція продовжувати стару стратегію.

Нові рішення користувача визначають напрям. Числа й методичні факти
визначаються даними та кодом, а не назвою цього чи будь-якого іншого плану.

## Межі доступу

AI використовує GitHub **тільки для читання**. Заборонені прямі зміни,
коміти, push, видалення, PR й автоматичний відкат. Виправлені файли
передаються в чаті; публікує їх виключно користувач.

Дослідження виконується дистанційно; доступ до київської лабораторії
не є передумовою. Не запускати новий extraction, навчання чи перезапис
заморожених результатів без погодженого завдання.
